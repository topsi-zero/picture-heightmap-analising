# A simple tool to edit pictures and color heightmaps

## Editing options:

<details>
  <summary> Pure RGB </summary>
    <br />
    <div align = "left">
      <h5>&nbsp;&nbsp;&nbsp;converts all colors to scales of pure red, green or blue</h5>
    </div>
</details>
<details>
  <summary> Black and White </summary>
    <br />
    <div align = "left">
      <li>converts the image into a grayscale version</li>
    </div>
</details>
<details>
  <summary> Random Color </summary>
    <br />
    <div align = "left">
      <li>gives every pixel a random color while keeping details</li>
    </div>
</details>
<details>
  <summary> Invert </summary>
    <br />
    <div align = "left">
      <li>inverts the colors of the image by a given factor</li>
    </div>
</details>
<details>
  <summary> Half Invert </summary>
    <br />
    <div align = "left">
      <li>only inverts the right side of the image with a smooth transition in-between</li>
    </div>
</details>
<details>
  <summary> Single Color </summary>
    <br />
    <div align = "left">
      <li>only uses either the red, green or blue values of each pixel</li>
    </div>
</details>
<details>
  <summary> Colored Heightmaps </summary>
    <br />
    <div align = "left">
      <li>insert a grayscale height map and the program will color every pixel by its height</li>
    </div>
</details>
