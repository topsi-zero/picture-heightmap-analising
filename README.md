## A simple tool to edit pictures and color heightmaps

<ul>
  <li>Open and edit images with a simple interface.</li>
  <li>Apply color adjustments to create custom heightmap effects.</li>
  <li>Generate and refine terrain-like textures from pictures.</li>
  <li>Export edited images in common formats.</li>
  <li>Preview changes in real time while editing.</li>
  <li>Use basic painting tools for detailed touch-ups.</li>
  <li>Organize workflow around quick, intuitive controls.</li>
</ul>
