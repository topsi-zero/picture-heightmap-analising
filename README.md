# A simple tool to edit pictures and color heightmaps

## Editing options:

<details>
  <summary>Pure RGB</summary>

  - converts all colors to scales of pure red, green or blue
</details>

<details>
  <summary>Black and White</summary>

  - converts the image into a grayscale version
</details>

<details>
  <summary>Random Color</summary>

  - gives every pixel a random color while keeping details
</details>

<details>
  <summary>Invert</summary>

  - inverts the colors of the image by a given factor
</details>

<details>
  <summary>Half Invert</summary>

  - only inverts the right side of the image with a smooth transition in-between
</details>

<details>
  <summary>Single Color</summary>

  - only uses either the red, green or blue values of each pixel
</details>

<details>
  <summary>Colored Heightmaps</summary>

  - insert a grayscale height map and the program will color every pixel by its height
</details>
